# Warranty Tracker

Keep warranties, maintenance, recalls, receipts, and replacement parts connected to the products they belong to.
</div>

## About

Warranty Tracker is a full stack home asset management project designed around one simple idea: your belongings should be easier to care for.

Instead of keeping receipts, warranty dates, maintenance notes, and recall information in different places, the application keeps everything organized around each asset.

## What it tracks

**Assets**  Appliances, electronics, vehicles, baby products, and home equipment

**Warranties**  Providers, coverage dates, status, and receipts

**Maintenance**  Upcoming tasks, completion history, and recurring care schedules

**Recalls and parts**  Product recall information and useful replacement part links

## Built with

Java · Spring Boot · Spring Data JPA · PostgreSQL · Maven · GitHub Actions

## Project focus

The backend follows a clear Controller → Service → Repository → PostgreSQL flow, with validation, API error handling, automated tests, and defect tracking through GitHub Issues.
